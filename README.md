This was a fun simple project made to create a light & dark theme for a webpage utilizing good color schemes for both modes
Below are some of the things I learned / Practiced from creating this project


HTML:
- practiced using the checkbox input type
- creating a good navigation section with anchor tags using "#section format so the page automatically scrolls to the desired section.
- practiced using Divs to create each page section as well as containers for my images and buttons
- made use of Font Awesome icons and wrapped them in links to popular songs as well as making them open in a new tab


CSS:
- Learned how to use CSS variables and setting them up for both theme modes
- practiced using flex display
- practiced giving each section a min-height of 100vh so each one will take entire page


JS:
- practiced creating global variables as well as using .getElementById method for DOM manipulaion
- Practiced / learned to use ternary operator to clean up the toggleDarkLightMode function
- created a switchTheme function which activated on the checkbox HTML element being turned on or off
- Learned how to make the theme setting register in local storage so users can load into the web page with the theme they left off on.
